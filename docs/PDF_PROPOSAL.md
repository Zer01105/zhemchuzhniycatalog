# PDF export proposal

## Цели

- PDF по текущему фильтру каталога.
- PDF по избранному из `localStorage`.
- Не смешивать генерацию PDF с текущими API тегов, импорта и комплектов.

## Подход

Рекомендуемый первый вариант: HTML print approach.

- Создать отдельные print-страницы с компактной версткой карточек.
- Пользователь открывает страницу, проверяет состав и печатает через браузер в PDF.
- Плюс: не нужна тяжелая серверная библиотека, меньше рисков с кириллицей, фото и внешним каталогом.
- Минус: PDF сохраняется вручную через браузер.

Серверную генерацию можно добавить вторым этапом через Playwright, если нужен один клик "Скачать PDF".

## Файлы для HTML print

- `app/print/catalog/page.tsx` - печатная страница по текущему фильтру.
- `app/print/favorites/page.tsx` - печатная страница по избранному.
- `app/section/[section]/page.tsx` - кнопка перехода к печати текущего фильтра.
- `app/favorites/page.tsx` - кнопка перехода к печати избранного.
- `app/globals.css` - `@media print` стили.
- `components/PrintProductCard.tsx` - общая карточка для печати.

## Файлы для серверного PDF, если понадобится

- `app/api/pdf/catalog/route.ts` - генерация PDF по фильтру.
- `app/api/pdf/favorites/route.ts` - генерация PDF по переданным избранным.
- `package.json` - добавить `playwright` или `@react-pdf/renderer`.
- `next.config.ts` - проверить server external packages при необходимости.

## Библиотека

Для второго этапа предпочтительнее Playwright:

- корректно рендерит текущий HTML/Tailwind;
- поддерживает кириллицу через браузерные шрифты;
- проще переиспользовать текущие карточки и изображения `/api/preview`.

`@react-pdf/renderer` менее удобен для текущего проекта, потому что потребует отдельной PDF-верстки и ручной настройки шрифтов.
